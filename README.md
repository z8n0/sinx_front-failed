این پروژه , پروژه ای مشترک بین من و یکی از دوستانم بود در زمان قطعی اینترنت و الان شکست خورده 

اگر میتونی ازش برای خودت استفاده کنی استفاده کن
#

برای استفاده:

برای نصب پکیچ های مورد نیاز
```npm i``` 

برای ران کردن پروژه:
```npm run dev``` 
برای ران کردن پروژه روی ای پی لوکال
``` npm run dev:host ``` یا ```npm run dev --host```

و پروژه روی  ```http://localhost:3000‍‍‍```
